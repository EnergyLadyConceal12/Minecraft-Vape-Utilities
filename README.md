# The longer version

Keep the extracted folder as is. The program looks for its files next to `setup`.

# Things people ask

</details>

No. Windows 10 is the earliest release that can run this.
</details>

<details><summary>I only want one small change. Is a single issue the right size?</summary>

Yes. One issue about the one thing you wanted is enough.
</details>

It will not. The zip has to become a real folder first, with `setup` as a normal file inside it.
</details>

# Install

- Do not start the program from inside the zip.
- Unpack to a normal folder before you begin.
- Bring up `setup` from the unpacked folder.

---

# Requirements

Nothing exotic:

- Version 10 of Windows, or a later release, is what this needs.
- This program requires a 64-bit version of Windows to run.
- Running the build does not depend on a compiler or a source tree.
- Neither a compiler nor a source tree is needed to run it.
- A 64-bit edition of Windows is what this build expects.
- The extracted files must remain in a single folder for the program to function properly
